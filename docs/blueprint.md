# **App Name**: ZR ESPORTS

## Core Features:

- Live Match Ticker & Announcements: Real-time scrolling notice bar for game announcements and site updates, dynamically managed via a centralized dashboard.
- Mobile-First Wallet & Finance: Comprehensive wallet section supporting Bkash and Nagad deposit requests and withdrawal management, persisted in Firestore.
- Esports Tournament Hub: Browse and participate in Free Fire match modes including CS Rank 4v4, Solo BR, and Lone Wolf with dynamic entry fees.
- Performance-Based Rewards: Automated reward system that calculates winnings or penalties (kill rewards and match bonuses) and updates user balances instantly.
- Real-time Match Auditor Tool: An AI-powered tool used to analyze match data trends and automatically recommend prize pool adjustments to the admin.
- Omnichannel Auth Tabs: Sleek Sign In and Register interface built for high conversion and mobile accessibility.
- Unified Command Panel: Powerful mobile-responsive admin suite at /admin for managing user accounts, verifying transaction IDs, and editing tournament rules.

## Style Guidelines:

- Primary color: Electric Violet (#8b5cf6) to evoke high-performance gaming energy.
- Background color: Deep Onyx (#121118), a heavily desaturated dark violet providing high contrast for competitive UI.
- Accent color: Neon Azure (#8e94f2) for auxiliary UI elements and highlighting player rankings.
- Font pairing: 'Space Grotesk' (sans-serif) for high-impact gaming headers; 'Inter' (sans-serif) for tabular tournament data and UI readability.
- Monochrome, line-weight focused icons representing match types, weapons, and wallet security.
- Mobile-first layout with persistent bottom navigation (Home, Wallet, History, Profile) and spacious, cards-based data entry.
- Slide-in transitions for switching views and horizontal marquee physics for the notice ticker.
